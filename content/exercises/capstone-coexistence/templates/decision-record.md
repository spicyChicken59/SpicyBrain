# Decision record

*One record per material decision (for example: the provisional path; the
wave-1 scope; the price-list sharing design; the Tessaly residency control;
the Granite notice decision). Fictional engagement; self-assessed exercise.*

| Field | Entry |
|---|---|
| Decision id | |
| Title | |
| Date | |
| Status | proposed / agreed / superseded |
| Decision owner | role, not a person |
| Context | The facts (pack, disclosures) and constraints this decision responds to |
| Decision | One sentence, present tense |
| Alternatives considered | Each with the reason it was not chosen *now* |
| Assumptions (labelled) | Each with the evidence that would confirm or refute it |
| Unknowns that could change this | Each with an owner and the decision it blocks |
| Consequences | What becomes easier, what becomes harder, what is now owned by whom |
| Reversal conditions | Specific, dated, owned: what evidence reverses this decision |
| Reversibility | How the previous state is restored, and by when it can no longer be |
| Cost effect | Which worksheet line changes, in which direction; no savings claim |
| Sentences that must not drift | Verbatim controls this record carries (for example a residency control) |
