# Teaching interaction references

Read 20 September 2026. These references informed interaction choices; the app, diagrams and teaching prose are original. They do not establish medical efficacy or prove learner preference.

| Primary reference                                                                                                                                                                             | Observed pattern and adopted decision                                                                                                                                                                   |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [Brilliant](https://brilliant.org/)                                                                                                                                                           | A visual idea and a guiding question form a small teaching unit. Its present AI product and efficacy/marketing claims are not adopted.                                                                  |
| [3Blue1Brown neural-network companion](https://www.3blue1brown.com/lessons/neural-networks/)                                                                                                  | Illustrated prose and worked examples connect the visual model to explanation. The course handbook shares actual concept/visual references with the deck. No copied artwork or proprietary slides.      |
| [Seeing Theory basic probability](https://seeing-theory.brown.edu/basic-probability/index.html)                                                                                               | Archived visual teaching reference: explicit states and outcomes matter more than decorative motion. Course state changes are learner-controlled and synthetic where labeled.                           |
| [Nutshell](https://ncase.me/nutshell/)                                                                                                                                                        | Optional context close to the relevant term reduces unnecessary navigation. Definitions are explicitly authored rather than indiscriminate auto-linking.                                                |
| [W3C clear steps](https://www.w3.org/WAI/WCAG2/supplemental/patterns/o1p04-clear-steps/) and [low cognitive demands](https://www.w3.org/WAI/WCAG2/supplemental/patterns/o6p05-low-cognition/) | One course hierarchy, predictable previous/next, optional depth, explicit save/resume and reduced navigation-memory demand. These are accessibility patterns, not a diagnosis-specific treatment claim. |
| [W3C hover/focus content](https://www.w3.org/WAI/WCAG22/Understanding/content-on-hover-or-focus.html)                                                                                         | Definitions remain hoverable/persistent, open on keyboard focus and touch, dismiss with Escape, return focus, and are measured against viewport edges.                                                  |
| [YouTube required player functionality](https://developers.google.com/youtube/terms/required-minimum-functionality)                                                                           | Consent-gated, visible player with no autoplay; minimum dimensions; scoped origin referrer. The privacy-enhanced provider still makes third-party requests after consent. No weakened script CSP.       |

The supplied local HTML specimen was inspected at desktop and phone sizes as a separate design reference, not misrepresented as the deployed app. Before screenshots distinguish that specimen from the accepted application's original Today/reader. Shared SpicyChicken design guidance and pinned tokens/fonts/marks were inspected and retained; no shared design-system file was edited.

Real browser iteration corrected: oversized mobile beat navigation; a visual-grid class collision; disappearing touch definitions after store saves; bottom-edge definition clipping; cross-tab view contamination; missing module-specific resumption; missing new-question Notebook return links; accessible text accidentally shown as an extra arrow label; and unclear horizontally scrollable tables. Reduced previews in the visual review accompany actual native-size inspection, not an inference from thumbnails.
